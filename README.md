# 🧠 Brain Tumor Detection

A Python-based deep learning project for **detecting and classifying brain tumors** in medical images.

Using **YOLOv8**, the system identifies tumor types and localizes them with bounding boxes.

**Classes:** Glioma • Meningioma • No Tumor • Pituitary

### 🛠️ Technologies
Python • YOLOv8 • PyTorch • OpenCV • NumPy • Pandas
